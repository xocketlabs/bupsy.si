What it does

A roster of bots, not a chat box.

Each bot is its own character with its own job, its own engine, and its own sense of when to ask you first.

Your subscription, not ours

Bots run the Claude Code and Codex CLIs already on your Mac, billed to the plan you already pay for. bupsy never buys, resells or proxies model access.

Group chats

Put bots in one conversation. @mention one to ask it, and bots hand work to each other — with a ceiling, so they can't burn your quota talking forever.

Routines & standing goals

“Brief me every weekday at 7.” “Keep my inbox under a day old.” It checks on a schedule and acts only when something is off.

Asks before it acts

New bots are fully gated: anything beyond reading waits for you. If nobody answers, the answer is no. Loosen it per bot when it has earned it.

Every bot is a character

Fourteen plush faces that glance around, bounce while they work, and wiggle when they need you. Pick one, or let it choose.

Usage, honestly

Runs and tokens per bot, plus what that would cost at API rates — shown as a value, never as a bill, because on a subscription there isn't one.

Your credentials

bupsy runs the tools. It never holds the keys.

Signing in happens in your own CLI. There is no bupsy backend and no column in the database that could hold a credential — a test checks the live schema on every build to prove it.

  • ✓
    No servers. Ours, anyway.Transcripts are files on your disk.
  • ✓
    Every decision is written down.The log is append-only, enforced by the database.
  • ✓

  • ✓

Install

Three steps.

Free. Works with the Claude Code or Codex sign-in you already have.

Download

Get Bupsy.dmg, open it, and drag Bupsy into Applications.

Sign in to an engine

Install Claude Code or Codex and sign in. bupsy finds it and never sees the credential.

Make a bot

Press ⌘N, give it a name and a job. It starts fully gated and asks before acting.

Opening it the first time: this early build isn't notarized by Apple yet, so macOS will say it can't check it. Open System Settings → Privacy & Security, scroll down, and click Open Anyway. Or run xattr -dr com.apple.quarantine /Applications/Bupsy.app. After that it opens normally.
